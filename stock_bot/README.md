# 📈 ETF AI自動売買ボット

過去5年のETFデータを分析し、テクニカル指標でBUY/SELL/HOLDを判定して**自動売買**するPythonボットです。  
**Alpaca**の無料ペーパートレード（模擬取引）から始められます。

---

## セットアップ手順

### 1. Alpacaアカウント作成（無料）

1. [https://app.alpaca.markets](https://app.alpaca.markets) でアカウント作成
2. ダッシュボード右上 **「Paper Trading」** を選択
3. 左メニュー **「API Keys」** → **「Generate New Key」**
4. API Key と Secret Key をコピー

### 2. インストール

```bash
# このディレクトリに移動
cd stock_bot

# 依存ライブラリをインストール
pip install -r requirements.txt

# .env ファイルを作成してAPIキーを設定
cp .env.example .env
# .env をテキストエディタで開いてキーを貼り付け
```

### 3. 動作確認（分析のみ・売買なし）

```bash
python bot.py --scan
```

出力例:
```
銘柄   シグナル  スコア  信頼度   RSI    現在値
NVDA   BUY      78.3   81%    58.2  $875.40
QQQ    BUY      71.2   75%    62.1  $441.20
SPY    HOLD     54.8   52%    55.8  $525.10
TLT    SELL     31.5   64%    38.2   $88.30
```

### 4. 実行

```bash
# 1回だけ実行（今すぐ売買判定）
python bot.py

# 毎日自動実行モード（市場オープン後 9:35 ET に実行）
python bot.py --watch
```

## 売買ロジック

### BUY条件
- スコア ≥ **65点** (0〜100点)
- 最大 **5ポジション** まで同時保有
- 1ポジション = ポートフォリオの最大 **20%**

### SELL条件
| 条件 | 詳細 |
|------|------|
| ストップロス | エントリーから **-7%** |
| 利確 | エントリーから **+20%** |
| シグナル反転 | スコアが **40点以下** に低下 |

### テクニカル指標（10種）
| 指標 | ウェイト |
|------|---------|
| SMA200 (長期トレンド) | 高 |
| SMA50 (中期トレンド) | 中 |
| SMA20 (短期トレンド) | 中 |
| RSI(14) | 高 |
| MACD | 中 |
| MACDヒストグラム傾き | 低 |
| ボリンジャーバンド位置 | 中 |
| 出来高トレンド | 低 |
| 5日モメンタム | 中 |
| SMA20傾き | 低 |

## パラメータ調整

`config.py` で変更できます:

```python
MAX_POSITIONS    = 5      # 最大ポジション数
MAX_POSITION_PCT = 0.20   # 1ポジション上限（20%）
MIN_BUY_SCORE    = 65.0   # BUYスコア閾値
SELL_SCORE_THRESH = 40.0  # SELLスコア閾値
STOP_LOSS_PCT    = 0.07   # ストップロス（7%）
TAKE_PROFIT_PCT  = 0.20   # 利確（20%）
```
